

# NXX Toolbox
[Haz clic para acceder a la Toolbox](https://www.nxxtoolbox.com)
## Desarrollo
### Frontend: 
- **Angular 11** 
- **SCSS**, diseño adaptable con **Bootstrap**.
### Backend: 
- API RESTful construida con **Express.js** para la recuperación de datos. [Haz clic para acceder al repositorio de la API](https://github.com/ALeafWolf/tears-of-themis-api)
- Recopilación de actividad de usuarios con **Google Analytics**.
### IDE: 
- VS Code
### Despliegue: 
- GitHub Page
## Ejecutar
* Después de descargar el archivo, ve a la consola y escribe
```
npm install
```
* Para ejecutar la aplicación en el entorno local, escribe
```
ng serve
```
* Luego abre `http://localhost:4200/` o el puerto que indique la consola en el navegador
